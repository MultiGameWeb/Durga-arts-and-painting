# Durga Arts & Paintings

A responsive portfolio and enquiry website for Durga Arts & Paintings, Hyderabad.

## Website
- GitHub Pages: https://multigameweb.github.io/Durga-arts-and-painting/
- Business contact: +91 80081 57900
- Services: School wall murals, play school paintings, interior wall art and canvas paintings.

## Files
- `index.html` — responsive single-page website
- `privacy.html` — privacy policy

## Portfolio images
The portfolio currently references the original project images in the existing `MultiGameWeb/Durga-arts` repository. This avoids duplicating the original photo files; keep that repository and its `img/` folder public for the images to load.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. The website will be available at the URL above after GitHub Pages finishes publishing.

## Notes
- No backend, login, analytics, payment gateway or contact-form database is included.
- WhatsApp and telephone links use the business contact number already published on the existing site.
